# Release Trust & Safety

Cette release doit rester compatible avec les offres historiques : elles ne sont pas rétroactivement dépubliées. Les nouvelles publications non vérifiées et les modifications substantielles par une entreprise non vérifiée passent par la file de modération.

La production ne doit être fusionnée qu'après validation GitHub Compliance, preview Vercel READY et tests transactionnels Supabase.
